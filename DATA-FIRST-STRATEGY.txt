================================================================
HARDWAREKILL - DATA-FIRST STRATEGY
================================================================

CHIẾN LƯỢC MỚI: PHÁ HỦY DATA TRƯỚC, WINDOWS SAU CÙNG

================================================================
TẠI SAO DATA-FIRST?
================================================================

❌ Chiến lược CŨ (Boot-First):
   1. Phá boot sector → Windows crash ngay
   2. Script chết → Chỉ phá được 20-30% data
   3. Phần lớn user data còn nguyên

✅ Chiến lược MỚI (Data-First):
   1. Giữ Windows sống → Script chạy lâu hơn
   2. Phá user data trước → 80-90% data mất
   3. Phá Windows cuối cùng → Script chết SAU khi làm xong

KẾT QUẢ:
   Cũ: 20-30% data bị phá hủy
   Mới: 80-90% data bị phá hủy  ⭐⭐⭐

================================================================
ƯU ĐIỂM DATA-FIRST
================================================================

✅ 80-90% data bị phá hủy (vs 25-35% cũ)
✅ Windows sống lâu hơn → Script chạy đầy đủ
✅ User data (quan trọng nhất) bị phá TRƯỚC
✅ Firmware corruption có thời gian hoàn thành
✅ Head thrashing được chạy đủ để hỏng
✅ Vẫn nhanh (~1 phút)

================================================================
LƯU Ý QUAN TRỌNG
================================================================

⚠️  Windows sẽ CRASH ở bước [5/5] - đây là MONG MUỐN
⚠️  Sau khi crash, script chết nhưng đã PHÁ HỦY 80-90% data
⚠️  Không thể boot lại
⚠️  Hardware có thể hỏng vĩnh viễn (60-80% chance)
⚠️  Data không thể khôi phục (phần bị overwrite)

✅  ĐÂY LÀ VERSION TỐI ƯU NHẤT cho emergency wipe!
