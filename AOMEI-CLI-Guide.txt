AOMEI PARTITION ASSISTANT - COMMAND LINE GUIDE
================================================================
Date: 2026-01-31
Purpose: Using AOMEI CLI for Disk Wipe Operations
================================================================

=== INSTALLATION LOCATION ===
C:\Program Files (x86)\AOMEI Partition Assistant\PartAssist.exe

=== BASIC USAGE ===
1. Open Command Prompt as Administrator
2. Navigate to AOMEI directory:
   cd "C:\Program Files (x86)\AOMEI Partition Assistant"
3. Run commands using PartAssist.exe

=== GETTING HELP ===
PartAssist.exe /?
PartAssist.exe /help
PartAssist.exe /list        (List all disks and partitions)

=== COMMON PARAMETERS ===
/hd:N           - Select hard disk (N = disk number, starts from 0)
                  Example: /hd:0 (first disk), /hd:1 (second disk)

/resize:N       - Resize partition N
/move:N         - Move partition N
/setletter:N    - Set drive letter for partition N
/letter:X       - Assign drive letter X

/delete:N       - Delete partition N
/deleteall      - Delete all partitions on selected disk

/wipe:N         - Wipe partition N
/wipedisk       - Wipe entire disk
/method:N       - Wipe method (1=zero fill, 2=random, 3=DoD, etc.)

/out:file.log   - Export results to log file

=== DISK WIPE COMMANDS ===

1. LIST ALL DISKS:
   PartAssist.exe /list

2. WIPE ENTIRE DISK (Zero Fill):
   PartAssist.exe /hd:1 /wipedisk /method:1 /out:wipe.log

   /hd:1       - Target disk 1 (WARNING: Change number carefully!)
   /wipedisk   - Wipe entire disk
   /method:1   - Use zero fill (fastest, 1 pass)
   /out:       - Save log

3. WIPE SPECIFIC PARTITION:
   PartAssist.exe /hd:0 /wipe:2 /method:1

   /hd:0       - Disk 0
   /wipe:2     - Wipe partition 2
   /method:1   - Zero fill

4. SECURE WIPE (DoD 5220.22-M):
   PartAssist.exe /hd:1 /wipedisk /method:3 /out:secure_wipe.log

   /method:3   - DoD standard (3 passes, more secure)

5. DELETE ALL PARTITIONS THEN WIPE:
   PartAssist.exe /hd:1 /deleteall
   PartAssist.exe /hd:1 /wipedisk /method:1

=== WIPE METHODS ===
/method:1   - Fill sectors with Zero (1 pass) - FASTEST
/method:2   - Fill with Random data (1 pass)
/method:3   - DoD 5220.22-M (3 passes)
/method:4   - DoD 5220.28-STD (7 passes)
/method:5   - Gutmann (35 passes) - SLOWEST, MOST SECURE

=== SAFETY TIPS ===
⚠️  ALWAYS verify disk number before wiping!
⚠️  Use /list first to see all disks
⚠️  Disk 0 is usually your system disk - DO NOT WIPE!
⚠️  Test on virtual machine or non-critical disk first
⚠️  Use /out: parameter to keep logs

=== EXAMPLE WORKFLOW FOR WIPE-DISK TOOL ===

Step 1: List all disks
-------
@echo off
cd "C:\Program Files (x86)\AOMEI Partition Assistant"
PartAssist.exe /list > disklist.txt
type disklist.txt

Step 2: Show warning and confirm
-------
echo WARNING: About to wipe Disk 1
echo Press Ctrl+C to cancel, or
pause

Step 3: Wipe disk with logging
-------
echo Wiping Disk 1...
PartAssist.exe /hd:1 /wipedisk /method:1 /out:wipe_%date:~-4,4%%date:~-7,2%%date:~-10,2%.log
if %errorlevel% equ 0 (
    echo Wipe completed successfully!
) else (
    echo Wipe failed! Check log file.
)

=== INTEGRATION WITH YOUR WIPE-DISK TOOL ===

You can create a batch script that:
1. Runs your Install-AOMEI-Silent.bat (installs AOMEI)
2. Uses PartAssist.exe CLI to wipe target disks
3. Logs all operations
4. Shows results

Example skeleton:
-------
@echo off
REM Install AOMEI if not installed
if not exist "C:\Program Files (x86)\AOMEI Partition Assistant\PartAssist.exe" (
    call Install-AOMEI-Silent.bat
)

REM Set paths
set AOMEI_PATH=C:\Program Files (x86)\AOMEI Partition Assistant
set AOMEI_EXE=%AOMEI_PATH%\PartAssist.exe

REM List disks
"%AOMEI_EXE%" /list

REM Your wipe logic here...
